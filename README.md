# abelha-vitrine
Landing estática (pt-BR) para divulgar os produtos do Bruno no Facebook/Instagram.

## Rodar
    npx serve .
Abra http://localhost:3000. Deploy: qualquer host estático (Vercel, GitHub Pages).

## O que preencher
- `config.js`: links do APK bloqueador, Jarvis, Braga, WhatsApp (wa.me/55...), Instagram, Facebook, link "Quero meu site". Vazio = "Em breve".
- `index.html`: `og:url` (domínio final) e `og-image.png` (1200x630, criar e colocar na raiz).
- Nome oficial do app bloqueador (hoje "Bloqueador de Pornografia").
- Depoimentos reais na seção "Quem usa, recomenda".
